# REQ-01.002 Official Number Assignment

`As a sheep owner, I want be able to provide an official number to my animals, either at creation or later so that I can fulfill the regulation but have the flexibility of when I make the assignment.`

- Group: REQ-01 Individual Management
- Priority: Must have

## Description
The official number (AMD/TVD/BDTA in Switerland, ) can be provided by the sheep owner at any time of the individual mangement. Some time the officiation number might not be available when the owner create the entry and this myust possible to do later.

## Acceptance criteria
- For registered animals, each individual entry can have an official number associated.
- The official number can be empty.
- The official number is unique
- The official number cannot be used to reference the animal across the system.
