# REQ-01.001 Each individual must have a unique identifier 

`As a sheep owner, I want to have a unique identifier created for each sheep so that I can record information about them wihtout having to find a name or create a unique number.`

- Group: REQ-01 Individual Management
- Priority: Must have

## Description
Each individual has an ID assign to them at creation. This ID is not meant to be visible to the user if any other manual identifier is provide. This ID is immutable an is used to associate records or other element to an individual.

## Acceptance criteria
- A unique ID is created when a new individual is entered.
- This ID is immutable.
