# SEC-009 SAFECode Compliance (Software Assurance Forum for Excellence in Code)

**Applies to:** mobile, backend, web

## Guideline

Development practices must align with SAFECode secure development guidelines.

- Threat modeling: lightweight threat model (STRIDE-per-element) produced for every new feature.
- Security training: mandatory for all developers. Training materials reviewed annually.
- Vulnerability management: security findings tracked, remediated, and verified. SLA per SEC-008.
- Secure by design: security requirements defined during feature design, not retrofitted after implementation.
- Third-party assurance: all third-party components assessed for security before inclusion.

## Rationale

SAFECode provides industry-vetted secure coding practices that reduce common vulnerabilities through disciplined development processes.
