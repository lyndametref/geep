# BR-013: Lamb Individual Creation from Confirmed Birth

## Description

A confirmed birth proposes creating lamb Individual records, one per newborn. The user can create the individual(s) for the born lamb(s) at any time from the lambing observation.

## Rationale

Based on requirement REQ-04.005 — A confirmed lambing proposes creation of lamb records as well, this rule ensures the shepherd is prompted to register each newborn lamb as an Individual in the system. The proposal is a suggestion, not an automatic creation — the user retains full control over whether and when to formalize the new Individual.

## Applicability

Applies when a birth observation is recorded or viewed. A lamb-record creation proposal is presented for each newborn. The user may create, defer, or dismiss the proposal.
