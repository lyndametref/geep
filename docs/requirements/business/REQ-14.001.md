# REQ-14.001 The system includes expenditure tracking by category

## User Story
As a shepherd, I want to record expenses by category so that I can understand where my money is going.

## Group
[REQ-14 Financial Tracking](REQ-14.md)

## Criticality
Could have

## Description
The system must support recording expenditure items with the following categories: feed, veterinary, equipment, labor, and other custom categories. Each expenditure entry must include amount, date, category, and optional notes.

## Acceptance Criteria
- The system supports expenditure entries with amount, date, category, and notes.
- Predefined categories include feed, veterinary, equipment, labor, and other.
- Flock manager can add custom expenditure categories.
- Expenditure entries can be viewed and filtered by category and date range.
