# REQ-01.001 Each individual must have a unique identifier

## User Story
As a shepherd, I want a unique identifier to be created for each sheep so that I can record information about them without relying on names or manually assigning unique numbers.

## Group
REQ-01 Individual Management

## Criticality
Must have

## Description
Each individual is assigned an ID at creation time. This ID does not need to be visible to the user when another manual identifier is provided. The ID is immutable and is used to associate records and related elements with an individual.

## Acceptance Criteria
- A unique ID is created when a new individual is entered.
- This ID is immutable.
