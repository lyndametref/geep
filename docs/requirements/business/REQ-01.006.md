# REQ-01.006 Each individual can be represented by a portrait chosen from observations or by a procedurally generated icon.

## User Story
As a shepherd, I want each individual entry to have a visual representation so that I can identify animals quickly.

## Group
[REQ-01 Individual Management](REQ-01.md)

## Criticality
Should have

## Description
Each individual entry can be represented either by a portrait selected from observations or by a procedurally generated icon.

## Acceptance Criteria
- An individual entry supports a portrait selected from observations.
- An individual entry supports a procedurally generated icon when no portrait is selected.
