# REQ-15 User-Defined Event and Task Types

## User Story
As a flock manager, I want to define custom types for observations, interventions, planned tasks, predicted events, and waiting delays so that I can adapt the system to my specific farming practices without requiring product evolution.

## Description
The system must allow the flock manager to create, edit, and manage custom type definitions for observations, interventions, planned tasks, predicted events, and waiting delays. This enables the flock manager to tailor the system to their unique workflow.
