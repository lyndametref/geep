# REQ-03.001 The sheep owner can provide phenotype information.

## User Story
As a shepherd, I want to provide phenotype information for my sheep so that the system can support genotype deduction.

## Group
REQ-03 Phenotype and Genotype Deduction

## Criticality
Should have

The system must allow the sheep owner to enter phenotype information for an individual.

## Acceptance Criteria

- The list of criteria can be configured
