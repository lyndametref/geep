# REQ-01.007 Each individual entry can include a basic color pattern

## User Story
As a shepherd, I want to record the basic color pattern for each sheep so that I can easily distinguish animals visually.

## Group
[REQ-01 Individual Management](REQ-01.md)

## Criticality
Should have

## Description
The system should allow the user to select a basic color pattern for each individual entry from a configurable list of options. The flock manager can configure the available color pattern options. This field is optional and not required for MVP operation.

## Acceptance Criteria
- The user can select a basic color pattern for an individual from a list of options.
- The color pattern field is optional.
- The list of color pattern options can be configured by the flock manager.
