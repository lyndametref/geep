# REQ-13.006 The system supports reminders for routine care interventions.

## User Story
As a shepherd, I want operational reminders for routine care interventions so that important actions are not missed.

## Group
[REQ-13 Interventions and Care Management](REQ-13.md)

## Criticality
Must have

## Description
The system must support reminders for routine care interventions. New reminder types can be added as the product evolves.

## Acceptance Criteria
- The system supports reminders for hoof trimming.
- The system supports reminders for shearing.
