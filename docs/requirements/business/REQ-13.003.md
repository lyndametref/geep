# REQ-13.003 Individuals can be selected for batch interventions through filters or manual selection.

## User Story
As a shepherd, I want to select animals efficiently for batch intervention operations so that I can apply actions to the right set of individuals.

## Group
[REQ-13 Interventions and Care Management](REQ-13.md)

## Criticality
Must have

## Description
The system must allow individuals to be selected for batch interventions either through filters, such as age or sex, or through manual selection. This capability mirrors observation selection ([REQ-04.003](REQ-04.003.md)).

## Acceptance Criteria
- Individuals can be selected through an age filter.
- Individuals can be selected through a sex filter.
- Individuals can be selected manually.
