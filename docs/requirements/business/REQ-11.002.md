# REQ-11.002 Web users can create, review, and edit records with genealogy and calendar views.

## User Story
As a shepherd, I want to review and complete data from the web application so that office workflows are efficient and accurate.

## Group
REQ-11 Multi-Application Workflow

## Criticality
Should have

## Description
Web users can create, review, and edit records, including genealogy and calendar information.

## Acceptance Criteria
- Web users can create records from the web application.
- Web users can review and edit records from the web application.
- Web users can access genealogy and calendar views for review and editing any records and entries.
