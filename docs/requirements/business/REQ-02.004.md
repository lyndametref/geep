# REQ-02.004 The genealogy view supports filtering by ancestry and life/death status.

## User Story
As a shepherd, I want to filter the genealogy view by relationship and status so that I can focus on relevant animals.

## Group
REQ-02 Genealogy and Parentage Graph

## Criticality
Should have

## Description

The genealogy view must support filtering 
- by ancestry:
    - all descendants of a selected individual
    - all ancestors of a selected individual
- by life/death status.

## Acceptance Criteria
- The genealogy view supports filtering to show all descendants of a selected individual.
- The genealogy view supports filtering to show all ancestors of a selected individual.
- The genealogy view supports filtering by life/death status.
