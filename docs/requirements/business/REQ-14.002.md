# REQ-14.002 The system includes income tracking by source

## User Story
As a shepherd, I want to record income by source so that I can understand my revenue streams.

## Group
[REQ-14 Financial Tracking](REQ-14.md)

## Criticality
Could have

## Description
The system must support recording income items with the following sources: meat sales, wool sales, animal sales, subsidies, and other custom sources. Each income entry must include amount, date, source, and optional notes.

## Acceptance Criteria
- The system supports income entries with amount, date, source, and notes.
- Predefined sources include meat sales, wool sales, animal sales, subsidies, and other.
- Users can add custom income sources.
- Income entries can be viewed and filtered by source and date range.
