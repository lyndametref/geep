# REQ-13.001 Intervention types include treatment, shearing, hoof trimming, and other care actions.

## User Story
As a shepherd, I want to record different kinds of interventions so that I can track all performed actions affecting my animals.

## Group
REQ-13 Interventions and Care Management

## Criticality
Must have

## Description
Intervention types include treatment administration, shearing, hoof trimming, and other care actions. The list of supported intervention types can be extended over time.

## Acceptance Criteria
- The system supports interventions of multiple types.
- In the MVP, core interventions are available: treatment, shearing, and hoof trimming.
- New intervention types can be added through product evolution.
