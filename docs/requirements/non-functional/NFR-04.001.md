# NFR-04.001 Zero UX Friction Security

## Description

Usability is critical for field work; security must be efficient and invisible. Security controls must operate with zero UX friction: users must never be asked to configure encryption settings or perform manual security actions for data access beyond the initial authentication step. Authentication (including MFA when required) is the only acceptable security gate, and its interaction must be minimized.

## Rationale

Field workers (farm staff, veterinarians) must be able to use the system quickly and without interruption. Complex security procedures would impede adoption and slow down fieldwork. Addresses the usability and security quality attributes, balancing protection with operational efficiency.

## Verification Method

Verified by reviewing all user-facing security workflows and confirming that no manual security action (encryption configuration, re-authentication prompts for data access) is required beyond the initial authentication step. Authentication flow must be measurable for time-to-complete and minimized.
