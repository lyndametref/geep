# REQ-13.004: An intervention entry records quarantine periods for meat or milk.

As a shepherd, I want intervention entries to include quarantine details so that I can respect meat and milk withdrawal periods.

Group: REQ-13 Interventions and Care Management
Criticality Should have

## Description
A treatment intervention entry must support recording quarantine periods for meat and milk.

## Acceptance Criteria
- A treatment intervention entry supports recording a quarantine period for meat.
- A treatment intervention entry supports recording a quarantine period for milk.
