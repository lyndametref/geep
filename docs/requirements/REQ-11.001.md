# REQ-11.001: Mobile users can create and update individuals, observations, and care in the field.

As a shepherd, I want to create and update core field data from mobile so that information is captured directly where work happens.

Group: REQ-11 Multi-Application Workflow
Criticality Must have

## Description
Mobile users can create and update individuals, observations, and care in the field.

## Acceptance Criteria
- Mobile users can create individuals in the field.
- Mobile users can update individuals in the field.
- Mobile users can create observations and care in the field.
- Mobile users can update observations and care in the field.
