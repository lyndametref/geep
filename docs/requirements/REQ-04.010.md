# REQ-04.010: The system supports reminders for start of key care and reproduction activities.

As a sheperd, I want operational reminders for key care and reproduction activities so that important actions are not missed.

Group: REQ-04 Observations and Automated Events
Criticality Must have

## Description
The system must support reminders for key care and reproduction activities. New reminder types can be added as the product evolves.

## Acceptance Criteria
- The system supports reminders for hoof trimming.
- The system supports reminders for shearing.
